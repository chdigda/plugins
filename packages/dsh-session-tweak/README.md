# dsh-session-tweak

사용자·봇 메시지 아래의 **수정·삭제** 버튼으로 원본 세션 JSON 로그와 열린 대화에 변경을 바로 반영합니다. 저장 후 새로고침·세션 다시 열기가 필요하지 않으며, 백업·복구본을 만들지 않습니다.

## 설치

Harness의 **Plugins → + Add plugin**에 입력합니다.

```text
git+https://github.com/chdigda/plugins.git#path:/packages/dsh-session-tweak
```

플러그인 설치·갱신 자체에 Harness가 재시작이나 브라우저 새로고침을 요구하면 그 안내를 따르세요. 메시지 편집 때는 필요하지 않습니다.

## 사용

- 실행 중에는 수정·삭제가 비활성화됩니다. 서버에서도 저장 직전에 확인합니다.
- 수정은 메시지 자리에서 편집하고 **저장·취소**합니다. Ctrl/Cmd+Enter로 저장하고 Escape로 취소합니다.
- 사용자·봇 모두 텍스트를 수정할 수 있으며, 수정 시 첨부·도구 호출 구조는 유지합니다.
- 삭제는 메시지와 연결된 도구 호출·결과를 제거합니다. 이후 대화는 유지합니다.
- 저장하면 현재 화면과 다른 열린 화면에도 바로 반영합니다. 입력 중인 다음 메시지는 유지합니다.

## 저장 방식

세션이 멈춰 있으면 잠깐 새 입력과 쓰기를 막고 남은 쓰기를 끝냅니다. 기존 에이전트·세션·writer·잠금을 그대로 유지한 채 JSON 로그를 교체하고, 같은 세션 객체의 대화와 캐시를 갱신합니다. 변경된 이벤트를 기존 화면의 데이터 원본에 전달하며, 파일을 다시 읽거나 세션을 다시 여는 방식이 아닙니다.

백업이나 변경 이력은 추가하지 않습니다. 교체용 임시 파일은 원본으로 이동되거나 실패 시 제거됩니다. 이벤트 참조가 어긋나지 않도록 삭제된 순번은 본문 없는 이벤트로 유지합니다.

## 호환성

- Node 24+, DSH **0.2.2-rc.1** 전용입니다. 내부 writer·세션 상태와 메시지 DOM 연결 지점에 의존합니다.
- 이미 압축 요약에 포함된 메시지는 오래된 요약과 새 본문이 어긋나므로 수정·삭제하지 않습니다.
- Windows 동작은 별도 실기기 검증이 필요합니다.
- 업데이트 화면은 아직 없습니다. 개발 버전은 같은 Git 주소로 다시 설치하세요.

# dsh-session-tweak

사용자·봇 메시지 아래의 **수정·삭제** 버튼으로 원본 세션 JSON 로그를 직접 바꿉니다. 별도 트윅 창이나 백업·복구본을 만들지 않습니다.

## 개발 버전 설치

Harness의 **Plugins → + Add plugin**에 입력합니다.

```text
git+https://github.com/chdigda/plugins.git#dev&path:/packages/dsh-session-tweak
```

설치·갱신 후 DSH를 한 번 재시작하고 브라우저를 새로고침하세요. 설치 전부터 열려 있던 세션은 writer 소유권을 추적할 수 없어 재시작 전에는 수정되지 않습니다.

## 사용

- 실행 중에는 수정·삭제가 비활성화됩니다. 서버에서도 저장 직전에 확인합니다.
- 수정은 메시지 자리에서 편집하고 **저장·취소**합니다. Ctrl/Cmd+Enter로 저장하고 Escape로 취소합니다.
- 사용자·봇 모두 텍스트를 수정할 수 있으며, 수정 시 첨부·도구 호출 구조는 유지합니다.
- 삭제는 메시지와 연결된 도구 결과를 제거합니다. 이후 대화는 유지합니다.
- 저장 후 페이지를 다시 불러와 파일·메모리·화면을 일치시킵니다.

## 저장 방식

세션이 멈춰 있으면 남은 로그 쓰기를 끝내고 해당 writer를 닫습니다. 저장 직전 메시지 버전을 확인하고, 같은 세션의 신규 실행을 잠시 막은 상태에서 JSON 로그를 교체합니다. 백업이나 변경 이력은 추가하지 않습니다. 교체용 임시 파일은 원본으로 이동되거나 실패 시 제거됩니다.

이벤트 참조가 어긋나지 않도록 삭제된 메시지의 순번은 빈 이벤트로 유지하며, 본문과 어시스턴트 스트림은 실제 로그에서 제거·교체합니다. 과거 surface 교체를 추가하는 방식은 사용하지 않습니다.

## 호환성

- Node 24+, DSH **0.2.2-rc.1** 전용입니다. 내부 writer·세션 수명 주기와 메시지 DOM 연결 지점에 의존합니다.
- 이미 압축 요약에 포함된 메시지는 오래된 요약과 새 본문이 어긋나므로 수정·삭제하지 않습니다.
- Windows 동작은 별도 실기기 검증이 필요합니다.
- 업데이트 화면은 아직 없습니다. 개발 버전은 같은 Git 주소로 다시 설치하세요.

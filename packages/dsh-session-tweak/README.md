# dsh-session-tweak

DSH 세션의 모델 컨텍스트에서 메시지를 수정하거나 제거하는 플러그인입니다.

## 설치

Harness의 **플러그인 → + 플러그인 추가**에서 다음 Git 주소를 넣습니다.

```
git+https://github.com/chdigda/plugins.git#path:/packages/dsh-session-tweak
```

## 사용

세션 헤더의 **트윅** 버튼을 누르면 현재 세션의 모델 컨텍스트 목록이 열립니다.

- **사용자 메시지 수정**: 다음 요청부터 모델이 수정된 텍스트를 봅니다. 첨부·참조 블록은 유지됩니다.
- **메시지 삭제**: 사용자·어시스턴트 메시지를 모델 컨텍스트에서 제거합니다. 어시스턴트 메시지에 도구 호출이 있으면 해당 도구 결과도 함께 제거합니다.
- 진행 중인 턴이 있으면 동작하지 않습니다. 턴이 끝난 뒤 다시 시도하세요.

## 동작 방식

DSH 세션 로그는 append-only이고, 모델이 보는 대화는 로그에서 파생된 surface입니다. 이 플러그인은 기존 이벤트를 지우지 않고 surface 교체 이벤트를 추가합니다.

- 화면의 원래 대화 기록은 그대로 남습니다. 목록에서의 수정·삭제는 **다음 요청부터 모델이 보는 내용**에 적용됩니다.
- 원본 로그와 과거 이력은 보존되며, 잘못 적용한 경우에도 대화 기록이 파괴되지 않습니다.

## 제한

- 어시스턴트(봇) 메시지 본문 수정은 지원하지 않습니다. DSH 런타임이 어시스턴트 메시지의 surface 교체를 허용하지 않습니다. 삭제만 가능합니다.
- 세션이 현재 DSH 프로세스에서 열려 있어야 합니다.
- 컨텍스트 주입 메시지, 시스템·개발자·도구 결과 노드는 목록에 표시되지 않습니다.

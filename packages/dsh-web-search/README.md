# DSH Web Search

> 컬렉션 관리자(`dsh-plugins`)로 설치하면 이 플러그인의 설치·업데이트 상태를 한 화면에서 확인하고 갱신할 수 있습니다. 링크 하나 설치는 [저장소 루트 README](../../README.md)를 참고하세요.

Tavily 검색과 Brave 대체 검색을 제공하는 DSH 플러그인입니다. 웹 페이지 읽기는 기존 HTTP 제공자를 사용합니다.

## 설정

**Plugins → Installed → dsh-web-search**에서 설정합니다.

- 패키지 활성화 스위치: 검색 플러그인 전체 켜기·끄기
- Tavily 사용 / Brave 사용: 각 공급자를 독립적으로 켜기·끄기
- API 키 입력 후 저장: 새 키 저장 또는 기존 키 교체
- 저장된 키 삭제: 해당 공급자의 저장된 키만 즉시 삭제
- 기본 검색 공급자: Tavily → Brave, Brave → Tavily, Tavily만, Brave만 중 선택

설정은 저장한 다음 검색부터 반영됩니다. 꺼진 공급자는 직접 호출과 대체 검색에서 제외되며, 둘 다 끄면 검색하지 않습니다. 실행 중인 요청을 취소하는 기능은 아닙니다. 선택한 공급자가 꺼져 있으면 해당 호출은 오류로 끝납니다.

키 입력란을 비워 두면 기존 키를 유지합니다. 키는 DSH 자격 증명 저장소에 보관하며 화면으로 다시 읽어오지 않습니다. 환경변수로 공급된 키는 삭제 버튼으로 지울 수 없으므로, 그 경우 공급자를 끄거나 환경변수를 제거하고 DSH를 재시작하세요.

- Tavily 키 참조: `TAVILY_API_KEY`
- Brave 키 참조: `BRAVE_SEARCH_API_KEY`

성공한 검색이나 결과가 없는 검색은 다른 공급자로 중복 요청하지 않습니다. API 키 누락, 인증·할당량·일시 오류 때만 활성화된 대체 공급자를 사용합니다.

## 설치

Harness의 **Plugins → + Add plugin**에 아래 주소 전체를 입력하고 설치·활성화합니다.

```text
git+https://github.com/chdigda/plugins.git#path:/packages/dsh-web-search
```

저장소 전체가 아닌 이 플러그인만 설치합니다. 설치 후 Harness가 요구하면 재시작하고 브라우저를 새로고침하세요. 플러그인을 끄면 원래 DSH 검색 구성이 복원됩니다.

0.3.0부터 **플러그인 상세 → Components → web-search → 업데이트**에서 버전 확인·갱신합니다. 새 버전이 있을 때 확인 후 설치하며, 프로필 설정과 보안 자격 증명은 별도로 유지됩니다. 제거 후 재설치가 실패하면 같은 주소로 다시 추가하세요. 로컬 설치는 여기서 갱신하지 않습니다. 자세한 설치·이전·개발 방법은 [저장소 안내](../../README.md)를 참고하세요.

DSH 0.2.1-rc.5에서 확인했습니다. 추가 의존성이나 클라이언트 빌드는 필요하지 않습니다.
